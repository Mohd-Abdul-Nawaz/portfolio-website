# 💼 Personal Portfolio Website

A clean, responsive portfolio website built with **HTML5, CSS3, and Vanilla JavaScript**.  
Deployable on **GitHub Pages**, **Netlify**, or **Vercel** — free and instant.

---

## 📸 Features

- Responsive design (mobile-friendly)
- About, Skills, Projects, and Contact sections
- Smooth scrolling navigation
- Ready to embed your GitHub project links
- No build step — pure HTML/CSS/JS

---

## 🚀 Quick Start

### 1. Open locally
Simply open `index.html` in any web browser.

### 2. Deploy on GitHub Pages (Free)
```bash
# In the portfolio-website folder
git init
git add .
git commit -m "Initial portfolio"
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```
Then enable GitHub Pages in your repo settings → Pages → Branch: `main` → Save.  
Your site will be at: `https://YOUR_USERNAME.github.io/portfolio`

### 3. Deploy on Netlify (Drag & Drop)
- Go to [netlify.com](https://netlify.com)
- Drag and drop this folder
- Get a live URL instantly

---

## 🎯 How to Use

1. Replace all `[YOUR NAME]`, `[YOUR EMAIL]`, etc. placeholders
2. Add your live TaskFlow and CampusConnect links in the Projects section
3. Add your GitHub and LinkedIn URLs
4. Deploy and add the URL to your resume header
