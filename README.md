# 💼 Personal Portfolio Website

A clean, responsive portfolio website built with **HTML5, CSS3, and Vanilla JavaScript**.  
Deployed on **GitHub Pages** — free and instant.

---

## 📸 Features

- Responsive design (mobile-friendly)
- About, Skills, Projects, and Contact sections
- Smooth scrolling navigation
- Links to live deployed projects
- No build step — pure HTML/CSS/JS

---

## 🚀 Deployment (GitHub Pages)

This repo is already connected. In your repo settings → **Pages**:
- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`
- **Custom domain:** leave **blank**

**Live URL:** https://mohd-abdul-nawaz.github.io/portfolio-website/

> ⚠️ **Do not** enter `mohd-abdul-nawaz.github.io` in the Custom domain field. That points at
> the root account domain where nothing is hosted, and it will break the site.

To redeploy after changes, just push to `main` — GitHub Pages rebuilds automatically.
